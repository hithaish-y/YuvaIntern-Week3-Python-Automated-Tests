# YuvaIntern Week 3 - Automated Tests

## Python Calculator Module

This project was created for the YuvaIntern Week 3 task on writing automated tests for Python applications.

The project contains a simple calculator module with functions for:

- Addition
- Subtraction
- Multiplication
- Division
- Power calculation
- Checking whether a number is even

## Files

- `calculator.py` - Python module containing the calculator functions.
- `test_calculator.py` - Automated tests using Python's built-in `unittest` framework.
- `README.md` - Project documentation.

## Testing

The test suite contains 8 test cases covering normal operations and error handling.

The tests cover:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Division by zero
6. Power calculation
7. Even number checking
8. Odd number checking

## How to Run

Open the project folder in VS Code and run:

```bash
python -m unittest test_calculator.py
